Podemos destacar palavras usando diferentes elementos

Sobre elemento Strong

Strong seria a forma de destacar o conteúdo de forma mais enfática, e para acessibilidade mostrando que é importante. Por exemplo, HTML

Sobre elemento b/bold

Bold seria a forma de destacar o conteúdo de forma mais enfática, mas não necessariamente importante. Por exemplo, HTML

Sobre elemento i/italic

Italic seria forma de destacar o conteúdo de forma mais suave, geralmente usado para nomes de livros, termos estrangeiros, ou para dar destaque a uma palavra específica. Por exemplo, HTML
