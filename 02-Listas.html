Sobre elementos listas

Listas são umas das coisas mais importantes do HTML. Ela sempre aparece em páginas web.

Conhecendo a lista

Lista não ordenada (UL)

Usamos a lista não ordenada quando a ordem dos itens não é importante

  • Item 1
  • Item 2
  • Item 3
  • Item 4

Lista ordenada (OL)

Aqui, nessa estrutura, a ordem como os itens são apresentados na tela importa.

  1. Item 1
  2. Item 2
  3. Item 3
  4. Item 4

Lista aninhadas

Listas aninhadas são listas dentro de listas. Elas podem ser ordenadas ou não ordenadas.

  • Areas

    • Front End
    • Back End
    • Full Stack

  • Design

    • UI
    • UX
    • O que estudar
      1. Design de Interação
      2. Design Visual
      3. Design de Produto

Lista de descrição (DL)

Esse tipo de lista é usada para descrever conceitos ou termos.

HTML
Linguagem utilizada para estruturar páginas da web.
CSS
Linguagem utilizada para estilizar páginas da web.
JavaScript
Linguagem de programação utilizada para adicionar interatividade às páginas da web.
