Iframe

Para que serve?

O Inline Frame (iframe) é um elemento HTML que permite embutir outro documento ou conteúdo dentro de uma página web. É comum usar para exibir conteúdo de outros sites, como vídeos do YouTube, mapas do Google Maps, ou formulários de terceiros, etc.
