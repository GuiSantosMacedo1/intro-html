Conhecendo o elemento de Details

Entendendo a estrutura

O elemento <details> é um elemento semântico do HTML5 junto com o elemento <summary>.

O que é o elemento details?

O elemento <details> é usado para criar um widget interativo que permite ao usuário revelar ou ocultar informações adicionais. Ele é frequentemente usado para fornecer detalhes adicionais sobre um tópico, como FAQs, descrições de produtos ou informações suplementares.

  • Permite revelar/ocultar informações
  • Usado para FAQs, descrições de produtos e informações suplementares
